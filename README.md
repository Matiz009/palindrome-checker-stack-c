# Palindrome Checker Using a Stack (C)

Checks whether a word is a palindrome in C, using an array-based stack.

## Features

- A menu to check a word or exit
- Pushes each character onto a stack, then compares characters from both ends
- Prints whether the word is a palindrome

## Tech stack

C

## Getting started

```bash
git clone https://github.com/Matiz009/palindrome-checker-stack-c.git
cd palindrome-checker-stack-c
gcc "palindromeChecker.c" -o palindromeChecker && ./palindromeChecker
```
